Country Explorer

Project Description

Country Explorer is a web application that allows users to explore countries around the world. Users can search for countries, view country information, filter by region, sort results, and save their favorite countries.

Features

* Search countries by name
* Display country flags
* Display capital cities
* Display population information
* Filter countries by continent
* Sort countries alphabetically
* Sort countries by population
* Add countries to favorites
* Remove countries from favorites
* Save favorites using LocalStorage
* Display favorite countries separately

Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* Async/Await
* JSON
* LocalStorage
* DOM Manipulation

APIs and Data Sources

* Countries Now API — country names, capitals and population data
* Local JSON file — region data
* FlagCDN — country flags

How to Use

1. Enter a country name in the search field.
2. Click Search to find a country.
3. Use the region filter to display countries by continent.
4. Use the sorting menu to sort countries by name or population.
5. Add countries to your favorites.
6. Click Favorites to view saved countries.
7. Click Show All to return to the full list.

Installation

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Open index.html using Live Server.

Project Goal

The goal of this project is to practice JavaScript, DOM manipulation, asynchronous programming, API integration, JSON data handling, filtering, sorting and LocalStorage.
